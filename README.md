# Blacksmith Holdings: Business Empire Simulation

A long-term, realistic business simulation. The player is the decision-maker (Chairman of Blacksmith Holdings). Claude acts as the simulation engine and the world around the player.

**Last saved state: about Aug 2281 (in-game).** The player currently plays **Advait Smith, Chairman** (since Jan 2269).

## Files
| File | What it holds |
|---|---|
| `CLAUDE.md` | Standing rules for running the simulation (read this first) |
| `state/current-state.md` | Where the simulation stands now |
| `state/company-register.md` | All group companies, heads and profits |
| `state/people-and-roles.md` | Leaders, roles, ages and pay structure |
| `state/governance-and-rules.md` | Deal limits, ceilings, delegations and standing directives |
| `state/decision-log.md` | Decisions taken, in order |
| `state/open-items.md` | What is waiting for the player |

## Notes
- All figures are in Rs crore (cr). Many names and numbers are simulation inventions, marked (sim).
- The early chat (before about Dec 2258) is not stored. Early facts come from saved project notes only.
- This is a fictional simulation.
